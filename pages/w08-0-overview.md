# 08주차. 중간고사 (범위 1~7주차)

중간고사는 **1~7주차** 내용을 범위로 한다.

## 시험 범위
- 1주차: 온디바이스 AI와 지능형 IoT 개론
- 2주차: 하드웨어 아키텍처(Memory Wall·NPU·Systolic Array·전성비)
- 3주차: 프레임워크·추론 엔진(ONNX·그래프 최적화·TFLite Delegate·TVM)
- 4주차: 모델 경량화 I — 프루닝
- 5주차: 모델 경량화 II — 양자화
- 6주차: 모델 경량화 III — 지식 증류
- 7주차: Neural Architecture Search(NAS)

## 평가 개요
- 배점 100점 · 시험 시간 약 90분 · 이론 70% / 실습 30%
- 구성: 객관식 · 단답형 · 서술형 · 계산/응용(혼합형)

> 실제 시험지와 정답·채점기준은 강의자·조교에게만 별도로 제공된다.
