# 07주차. NAS & Hardware-aware Design + 중간고사

> NAS & 하드웨어 인지형 설계 / 중간고사
> 주당 3시간 · **1교시 강의 + 2·3교시 중간고사**

## 이번 주차의 구성

7주차는 전반부 이론의 마지막 주차이자 **중간고사를 함께 치르는 주차**다. 1교시에 NAS와 하드웨어 인지형 설계를 압축 강의하고, 2·3교시에 중간고사를 시행한다.

| 교시 | 성격 | 내용 | 배정(분) |
|:---:|------|------|:---:|
| **1교시** | 강의(개론) | 1.1 NAS의 등장 배경 / 1.2 NAS의 3대 요소 / 1.3 탐색 전략 개관 / 1.4 Hardware-aware NAS와 파레토 프론티어 / 1.5 Once-for-All | 50 |
| **2·3교시** | **평가** | **중간고사** (범위 1~6주차) | 90 |

> 오늘 배우는 NAS(7주차)는 **시험 범위에 포함되지 않는다.** 같은 회차에 학습한 내용을 그날 출제하지 않는 것이 평가 타당성의 원칙이다.

## 학습 목표 (1교시)
- 사람이 설계한 아키텍처의 한계를 이해하고 NAS의 등장 배경을 설명할 수 있다.
- NAS의 3대 구성 요소(탐색 공간·탐색 전략·성능 예측)를 구분할 수 있다.
- Hardware-aware NAS가 **실측 지연**을 목적 함수에 넣는 방식과, 그것이 파레토 프론티어 탐색임을 설명할 수 있다.
- Once-for-All이 "학습 1회, 배포 다수"를 가능하게 한 원리를 설명할 수 있다.

## 중간고사 운영 안내

| 항목 | 내용 |
|------|------|
| **시험 범위** | **1~6주차** |
| **배점** | 100점 |
| **시험 시간** | 약 90분 (2·3교시) |
| **구성** | 객관식 · 단답형 · 서술형 · 계산/응용 (혼합형) |

**범위 세부**

- 1주차: 온디바이스 AI와 지능형 IoT 개론 — 지연 분해 모델, 4대 동인, 기술 스택 4계층, 제약 최적화 정식화
- 2주차: 하드웨어 아키텍처 — Memory Wall, NPU·Systolic Array, 메모리 계층, 전성비·DVFS
- 3주차: 프레임워크·추론 엔진 — ONNX, 그래프 최적화(Operator Fusion·Constant Folding 등), TFLite Delegate, TVM
- 4주차: 모델 경량화 I — 프루닝(비구조적·구조적, 희소성과 실제 속도의 괴리)
- 5주차: 모델 경량화 II — 양자화(Affine 매핑, 스케일·제로포인트, PTQ/QAT, 보정)
- 6주차: 모델 경량화 III — 지식 증류(Temperature, KL+CE 손실, 교사-학생 구조)

> 준비 지침: 각 주차의 "한 줄 정리"와 핵심 키워드를 축으로 복습하고, 계산 문항에 대비해 양자화 스케일·모델 크기·지연 추정 계산을 직접 손으로 풀어 볼 것.

> 실제 시험지와 정답·채점기준은 강의자·조교에게만 별도로 제공된다.

## 선수 연결
- 4~6주차의 경량화가 '주어진 모델을 다루는' 것이었다면, 7주차는 '모델 구조 자체를 탐색'한다.
- 1주차의 제약 최적화 정식화·파레토 프론티어가 여기서 실제 알고리즘으로 구현된다.
- 2주차의 하드웨어 지연이 목적 함수로 들어오는 Hardware-aware 설계로 완성된다.
- **중간고사(범위 1~6주차)를 이 주차에 함께 시행한다.**
