# 지능형 IoT를 위한 온디바이스AI — 강의교재

위키독스(wikidocs.net) **깃허브 연동**용 저장소입니다. `main` 브랜치에 push하면 연결된 위키독스 책에 자동 반영됩니다.

## 구조
- `TOC.md` — 목차(페이지 계층). 위키독스가 이 파일로 책 구조를 만듭니다.
- `pages/` — 페이지 마크다운. `wNN-교시-이름.md` 규칙.
- `assets/` — 그림(PNG). 페이지에서 `![설명](../assets/파일.png)`로 참조.
- `exams/` — 시험지·정답. **`.gitignore`로 제외**되어 공개 저장소에 올라가지 않습니다.

> **주차 제목은 반드시 두 자리(`01주차`, `02주차` …)로 표기하세요.** 위키독스가 제목 문자열 기준 알파벳순으로 정렬하기 때문에, 한 자리로 쓰면 `10주차`가 `2주차`보다 앞에 놓입니다.

## 연결 방법 (최초 1회)
1. 이 저장소를 본인 GitHub 계정으로 올립니다(공개 레포 권장).
2. 위키독스 로그인 → **새 책 만들기(깃허브 연동)** → GitHub 인증 → 이 저장소 선택.
3. 이후 `git push origin main` 할 때마다 책이 갱신됩니다.

## 갱신 방법

```bash
git add -A                       # 삭제·이름변경까지 반영하려면 . 이 아니라 -A
git commit -m "docs: 08주차 수정"
git pull --rebase origin main    # 원격이 앞서 있으면 먼저 정렬
git push origin main
```

`--force`는 사용하지 마세요. push가 거부되면 `git pull --rebase origin main`으로 원격 커밋 위에 다시 얹은 뒤 push합니다.
