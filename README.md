# 지능형 IoT를 위한 온디바이스AI 


---


## 14주 구성

| 주차 | 주제 | 비고 |
|:---:|------|------|
| 01 | 온디바이스AI와 지능형 IoT 개론 | |
| 02 | 온디바이스AI 하드웨어 아키텍처 | |
| 03 | 온디바이스AI 프레임워크 및 추론 엔진 | |
| 04 | 모델 경량화 I — 프루닝 | |
| 05 | 모델 경량화 II — 양자화 | |
| 06 | 모델 경량화 III — 지식 증류 | |
| **07** | **NAS & Hardware-aware Design + 중간고사** | 1교시 강의 + 2·3교시 시험 · 범위 1~6주차 |
| 08 | TinyML 및 초저전력 온디바이스AI | 3교시 실습은 **MCU 보드 불필요** |
| 09 | 엣지 기반 시각 지능 (Computer Vision on the Edge) | 3교시 실습은 **카메라·GPU 불필요** |
| 10 | 엣지 기반 언어 지능 및 On-Device LLM | 3교시 실습은 **GPU·API 키 불필요** |
| 11 | 실무 하드웨어 가속기 프로그래밍 | 3교시 실습은 **가속기 불필요** |
| 12 | 연합 학습 및 프라이버시 보호형 AIoT | 3교시 실습은 **노트북 한 대면 충분** |
| 13 | 최신 연구 동향 및 AIoT 학술 세미나 | 3교시 실습은 **논문 PDF 한 편이면 충분** |
| **14** | **기말 캡스톤 발표·평가** | 별도 기말 필기시험 없음 · 3교시 실습은 **보고서 한 편이면 충분** |

각 주차는 `개요 + 1교시 개론 / 2교시 심화 / 3교시 실습`으로 구성됩니다. 다만 **7주차는 중간고사를 함께 치르므로** 1교시만 강의이고 나머지 두 문서는 자율 학습 자료·선택 과제이며, **14주차는 세 문서를 발표 전에 읽고 실행해 오는 구성**(1교시 기준 · 2교시 채점 설계 · 3교시 제출 전 자가 점검)이며, 발표 당일 3시간은 오리엔테이션·팀 발표·종합 강평으로 씁니다.
