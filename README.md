# 4주차 교재 개편본 — 모델 경량화 I: 프루닝

1~3주차와 같은 톤(질문형 제목 · 일상 비유 · `[더 깊이 — 선택]` 분리)으로 전면 재작성했습니다.
시간 배분도 바로잡았습니다 — 기존 160분(2교시가 60분) → **50/50/50 = 150분**.

## 구성
- `pages/` — 주차 개요 + 1·2·3교시 (각 50분)
- `assets/` — 그림 11점 (PNG). 기존 6점 중 1점은 실측값으로 교체, 5점 신규
- `svg/` — 그림 원본 (수정용)
- `code/실습_전체.py` — 3교시 코드 블록을 그대로 이어 붙인 실행 스크립트
