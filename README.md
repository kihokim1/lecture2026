# 지능형 IoT를 위한 온디바이스AI — 강의교재

위키독스(wikidocs.net) **깃허브 연동**용 저장소입니다. `main` 브랜치에 push하면 웹훅이 트리거되어 연결된 위키독스 책에 자동 반영됩니다.

---

## ⚠️ 반영이 안 될 때 먼저 볼 것

| 증상 | 원인 | 해결 |
|---|---|---|
| **최상위(책 제목)가 이상하다** | 책 제목은 **TOC.md와 무관**하다. 위키독스 DB에 따로 저장된 값이다. | 위키독스 **책 설정 → `책 제목`** 에서 직접 수정. 재동기화로는 절대 안 고쳐진다. |
| 목차 제목이 본문과 다르다 | 개편 후 `TOC.md`를 안 고쳤다. 위키독스는 **본문 H1이 아니라 TOC.md의 대괄호 안 문자열**을 페이지 제목으로 쓴다. | `python3 sync_toc.py --write` 후 push |
| push했는데 안 바뀐다 | 웹훅이 안 떴다 | 책 편집 화면 **깃허브 탭 → `지금 동기화`** 클릭 |
| 로컬만 고쳤는데 안 바뀐다 | 위키독스는 **깃허브 저장소**를 본다 | `git push origin main` 필요 |
| `10주차`가 `2주차`보다 앞에 온다 | 위키독스는 **제목 문자열 기준 정렬** | 주차는 반드시 **두 자리**(`01주차`, `02주차` …) |

---

## 구조

```
TOC.md          목차. 위키독스가 파싱해 페이지 계층과 페이지 제목을 만든다.
sync_toc.py     배포 전 무결성 검사 · TOC 제목 자동 동기화
pages/          페이지 마크다운. wNN-교시-이름.md 규칙
assets/         그림(PNG). 페이지에서 ../assets/파일.png 로 참조
exams/          시험지·정답. .gitignore 로 제외되어 공개 저장소에 안 올라간다
```

### 파일명 규칙

| 종류 | 형식 | 예 |
|---|---|---|
| 페이지 | `wNN-{0,1,2,3}-{overview,intro,advanced,lab}.md` | `w06-3-lab.md` |
| 그림 | `wNN_pX_주제_번호.png` | `w06_p3_gain_source_11.png` |

## 배포 전 필수 검사

```bash
python3 sync_toc.py           # 검사만 (통과해야 push)
python3 sync_toc.py --write   # TOC 제목을 본문 H1로 자동 갱신
```

잡아 주는 것 — 목차/본문 제목 불일치 · 죽은 링크 · 고아 페이지 · 그림 참조 누락 · `.svg` 잔존 · 한 자리 주차 표기.

> **교재를 개편하면 페이지의 H1이 바뀝니다. 그때 `TOC.md`를 같이 안 고치면 목차와 본문이 어긋납니다.** 실제로 3~6주차 개편 때 15건이 어긋난 적이 있습니다. 개편 후에는 예외 없이 이 스크립트를 돌리세요.

## 표기 규약

- **`온디바이스AI`** — 붙여 씁니다. `온디바이스 AI`(띄어쓰기)는 쓰지 않습니다. 교재·시험지·슬라이드·**그림 내부 텍스트**까지 동일하게 적용합니다. 영문 `On-Device AI`는 그대로 둡니다.
- 전문 용어는 첫 등장에서 `한글(English)` 병기, 이후 한글 우선.
- 수식은 위키독스 MathJax 표기 — 인라인 `$...$`, 블록 `$$...$$`. 인라인에 `\( \)`를 쓰지 않습니다.
- 각 하위 목차 끝에 `> 한 줄 정리:`, 각 교시 끝에 `> 교수님을 위한 Tip:`.

## 연결 방법 (최초 1회)

1. 이 저장소를 GitHub 계정으로 올립니다(공개 레포 권장).
2. 위키독스 로그인 → **새 책 만들기(깃허브 연동)** → GitHub 인증 → 저장소 선택.
3. **`책 제목`을 직접 입력**합니다 — 「지능형 IoT를 위한 온디바이스AI」. 이 값은 TOC.md에서 오지 않습니다.
4. 이후 `git push origin main` 할 때마다 웹훅으로 자동 갱신됩니다.

## 갱신 방법

```bash
python3 sync_toc.py              # 먼저 검사 (실패하면 push하지 말 것)
git add -A                       # 삭제·이름변경까지 반영하려면 . 이 아니라 -A
git commit -m "docs: 06주차 개편"
git pull --rebase origin main    # 원격이 앞서 있으면 먼저 정렬
git push origin main
```

`--force`는 사용하지 마세요. push가 거부되면 `git pull --rebase origin main`으로 원격 커밋 위에 다시 얹은 뒤 push합니다.
